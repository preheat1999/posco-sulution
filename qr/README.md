# 자재식별표 QR

`make_qr.py` 가 만든 파일이다. 손으로 고치지 않고 다시 돌려서 만든다.

```bash
python -B make_qr.py --all                              # 등록된 자재 전부
python -B make_qr.py --code Q4046777                    # 한 건
python -B make_qr.py --base https://192.168.0.10:8443   # 다른 주소로 (사내망 · 노트북 · https)
python -B make_qr.py --page mobile-return.html           # 반납 화면으로 바로
```

## QR 에 담긴 값

```
<배포 주소>/material-view.html?code=Q4046777
```

스캔하면 **자재 확인 화면**이 열린다 · 식별표 값과 **반납자(사번 · 이름)** 를 확인하고
「반납 → 확인」 을 누르면 반납 화면으로 넘어가 2단계(자재정보 초안 확인)부터 이어진다.
자재는 `assets/qr-items.js` 에 **자재코드를 PK** 로 등록한다.

반납 화면으로 바로 보내려면 `--page mobile-return.html` 로 만든다.

## 파일

| 파일 | 무엇 |
|---|---|
| `Q4046777_qr.png` | 자재 확인 화면으로 · QR 만 · 한 칸 16px · 여백 4칸 |
| `Q4046777_qr.svg` | 같은 것 · 벡터 (크게 인쇄할 때) |
| `Q4046777_label.png` | 자재식별표 모양 · QR + 자재 정보 + 주소 |
| `Q4046777_mobile-return_*` | 반납 화면으로 바로 가는 QR (`--page` 로 만든 것) |

`--page` 로 만든 것은 이름에 그 화면이 붙는다. 같은 이름으로 덮어쓰면 어느 QR 이
어디로 가는지 알 수 없기 때문이다.

## 폰으로 테스트 (배포 전)

```bash
python -B serve.py                                        # 0.0.0.0:8130 · 폰이 붙을 수 있다
python -B make_qr.py --base https://<노트북 IP>:8443 --all  # 그 주소로 QR (https 라야 마이크가 열린다)
```

`serve.py` 가 띄울 때 폰으로 열 주소와 QR 만드는 명령을 같이 적어 준다.
폰이 안 붙으면 윈도 방화벽에서 그 포트를 한 번 허용해야 한다.

## 규격

- 오류복정 **M** (15% 훼손까지 읽힌다) · 식별표는 기름 · 긁힘이 있어 L 로 두지 않았다
- 버전 5 · 한 변 37칸 · 여백(quiet zone) 4칸
- 인쇄 크기는 **한 변 3cm 이상**을 권한다 (한 칸 0.8mm 이상)

## 만든 뒤 스스로 검사하는 것

`make_qr.py` 가 파일을 낼 때마다 아래를 확인하고, 하나라도 어긋나면 실패로 끝낸다.

1. 같은 값으로 다시 인코딩한 행렬과 한 칸도 다르지 않은가
2. PNG 픽셀이 QR 행렬과 한 칸도 다르지 않은가 (배율 · 여백 계산 실수를 잡는다)
3. 찾기 무늬 세 개가 규격대로 있는가 (7×7 겹 사각형)
4. 여백 네 귀퉁이가 비어 있는가

**실제 스캔은 사람이 해야 확인된다.** 위 검사는 「우리가 만든 그림이 규격을 지켰는가」 까지다.

## 주의

QR 은 절대 주소를 담는다. 그 주소에 **`material-view.html` 이 올라가 있어야** 열린다
(`assets/qr-items.js` 도 함께 올라가야 자재를 찾는다).
아직 배포하지 않았다면 `--base` 로 지금 열려 있는 주소(사내망 노트북 등)를 넣어 다시 만든다.

## 접속 QR (시연장에서 폰으로 들어오는 문)

```bash
python -B make_open_qr.py            # 지금 이 컴퓨터의 https 주소로 만든다
```

`qr/open_label.png` 한 장을 띄워 두면 사람들이 찍고 들어온다 ·
그림 안에 「고급 → 계속」 안내와 「https 라야 마이크가 열린다」 가 같이 적혀 있다.
와이파이가 바뀌어 IP 가 달라지면 다시 만들면 된다.
