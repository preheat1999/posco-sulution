## 무엇을 하는 화면인가

자재별 **목표재고**를 산출하고 현재고와 비교해 **발주 · 유지 · 감축**을 정한다.
속성(보험품/계획품)에 따라 **산식이 완전히 다르다.**

* 보험품 · 항상 들고 있어야 하므로 `min(ceil(μ_LT + SS), 관측상한)`
* 계획품 · **원칙 0.** 정비 일정에 맞춰 사면 된다

무재고 비중이 99.2% 로 나오는 것은 데이터가 빈 게 아니라 **계획품은 상시
재고 0 이 원칙**이기 때문이다. 화면에 그 뜻을 반드시 붙여 쓴다.

## 아코디언 규격

```
section.sect
  button.sh          머리. 누르면 열고 닫는다
    span.sn          파란 라운드 사각형 안 번호 (24px)
    span.st          <b>제목</b><span>부제</span>
    span.badge       오른쪽 요약 (건수 · 모드)
    svg.chevi        화살표. 열리면 위, 닫히면 아래
  div.sb             몸통
```

> **함정 · 실제로 당했다.** `.sect:not(.open) > .sb { display:none }` 을
> 빠뜨리면 **아코디언이 접히지 않는다.** 화살표만 돌아가고 내용은 그대로다.
> 그리고 화살표 방향을 반대로 두기 쉽다. 열림 = 위(∧), 닫힘 = 아래(∨).

기본 상태 · ③ ④ 만 열려 있다. ① ② ⑤ 는 접혀 있다.
담당자가 매일 보는 것은 「지금 사야 할 것」 과 「줄일 수 있는 것」 이다.

## ① 산출 산식

**화면이 계산하지 않는다.** 명세 상수(`meta.spec`)를 읽어 그대로 보여 준다.

```
전제 · INVENTORY 916,140행 전체에서 안전재고 · 최소 · 최대 · 리드타임 설정이 0건입니다.

보험품   μ_LT = 일평균소요 x 리드타임평균
        SS   = Z(등급) x 일표준편차 x sqrt(리드타임평균)
        norm = ceil(μ_LT + SS), 최소 ceil(1회소요규모) 보장
        raw  = min(norm, 관측상한)      관측상한 = 리드타임창 부트스트랩 400회 최대값
        핵심(CSP·CEQ=O) -> max(raw, 설치수기준, 1) · 비핵심 -> raw

계획품   핵심설비가 아니면 0
        최근 3년 무소요면 0
        소요가 활발하지 않으면 0 (λ < 1.0 또는 유휴 1.5년 초과)
        그 외 max(1, min(서비스수준 분위수, 상한 1))

등급별 Z   S 2.58 · A 2.05 · B 1.65 · C 1.28
```

> **등급 캡(상한) 개념은 없다.** 등급은 Z 로만 반영된다.
> 유일한 상한은 부트스트랩 관측상한이다. 이것을 헷갈리면 목표재고가 통째로 틀린다.

등급 규칙과 7요인 가중치도 함께 보여 준다
(F5 공용성 0.50 · F1 핵심설비 0.35 · F3 리드타임 0.05 · F4 대체성 0.04 ·
F6 고장확률 0.03 · F7 조달난이도 0.02 · F2 고장영향 0.01).

**F2 가 0.01 인 이유** · 원본 ERP 정비비가 보안으로 빠져 중위값 상수로
대체됐다. 값이 상수면 변별력이 없다. 이 사정을 화면에 적는다.

## ② 재고 vs AI 적정재고 비교

가로 막대 두 줄 (현재고 파랑 · 목표재고 초록) + 초과 구간 주황 배경.
오른쪽 배지로 **수량 / 금액** 을 전환한다. 차트는 직접 그린다.

## ③ 발주 필요 Alarm

`현재고 < 목표재고` 인 것. 오른쪽 끝에 `[부족]` 배지.
행을 누르면 근거 팝오버가 열린다 (`reason` 필드에 산식이 그대로 들어 있다).

```
비핵심보험[C] μ_LT+SS(Z1.28)=2,상한4→2
```

## ④ 과잉재고 Alarming

`현재고 > 목표재고` 인 것. **PFC 경과**를 함께 보여 준다.
PFC 창고 입고 후 180일이 넘으면 공용자재로 자동 전환된다.
「공용 전환」 버튼을 누르면 `DB.pool()` 로 3층에 기록되고
KPI 의 「절감 실현액」 이 올라간다.

## ⑤ 산출 제외 자재

왜 빠졌는지 명시한다. `배제-소모품`(Consignment · 일일공급품 · 자가재) ·
`배제-순환품`(Roll 계열). **숨기지 않고 이유와 함께 보여 주는 것**이 핵심이다.
