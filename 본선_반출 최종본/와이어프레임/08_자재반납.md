# 와이어프레임 08 · 자재반납 QR (`return.html`)

`window.PAGE = 'return'` · 그림 `이미지/return_pc.png` · `이미지/return_mobile.png`

---

## 무엇을 하는 화면인가

정비하고 남은 자재를 창고에 돌려보내는 일이다. **현장에서 가장 실수가 많다.**

* 반납 유형이 7갈래인데 유형마다 들어갈 메뉴와 창고가 다르다
* 반납 시 Account 는 **최초 불출 계정과 같아야 한다** (현장 최다 실수)
* Consignment 는 불출 후 3일 안에 원 창고, 넘으면 중앙창고

자재식별표 QR 을 찍으면 자재 · 불출이력 · 계정이 자동으로 조회되고
AI 가 반납 유형 · 반납 창고 · 결재 필요 여부를 판정한다.

## QR 카드

```
┌──────────────────┐
│    ┌──────────┐   │  120x120 QR 모양 아이콘 (모서리 4개 + 점)
│    │  ▩  ▩    │   │  --brand-weak 배경 · radius 14
│    │  ▩   ⋮    │   │
│    └──────────┘   │
│  자재식별표 QR 스캔  │  15px / 700
│  QR을 인식하면      │  11.5px / muted / 2줄
│  자재·불출이력·계정이 │
│  자동으로 조회됩니다  │
│  [    QR 스캔    ] │  .btn · 폭 100%
│  [Q코드 입력 ][추가] │  입력칸 + 작은 버튼 (버튼은 폭 100% 아님)
│  [📱 휴대폰으로 반납] │  .btn line · 폭 100%
│  [▩ 자재식별표 QR ] │  .btn line · 폭 100% -> material-view.html?code=...
└──────────────────┘
```

> **함정 · 실제로 당했다.** `.qrcard .btn{width:100%}` 를 자손 선택자로 쓰면
> 「추가」 버튼까지 100% 가 되어 옆의 Q코드 입력칸이 24px 로 찌그러진다.
> **직접 자식(`>`)에만** 준다.

## 반납 목록 열

| 열 | 내용 |
| --- | --- |
| 설비 · 조립품 · W/O | 어디서 나온 자재인지 |
| 자재명 · Q코드 | 정본에서 |
| 불출일 | `2026-09-01 · 2일 경과` |
| 상태 | 신품 / 중고 / 불용 / 철강재 / 투자 / Consignment |
| 잔여 | 불출 잔여 수량 |
| 반납수량 | `- 1 +` 스텝퍼 |
| AI 반납유형 | 7갈래 중 하나 + 거래코드 |
| 반납창고 | `QVC70` 중고품 / `QVC75` 불용 / `QVC77` 중앙야적장 / `QVC01~05,08` 중앙창고 |

「전체 스캔 (데모)」 버튼으로 10건을 한 번에 올린다. **시연용이라고 적는다.**

## ✦ Set자재 연관자재 추천

같은 W/O 에서 **동시 불출된 이력**을 근거로 「이것도 같이 반납하시겠어요?」.
동시 불출 비율(`80%` 처럼)과 근거 문장을 함께 낸다.

## 데이터 출처

| 값 | 출처 |
| --- | --- |
| 품명 · 단가 · 창고 · 속성 · 등급 | 정본 `DB.item()` |
| 불출일 · 물품상태 · 잔여 · 계정 · 위치 | 업무 `DB_BIZ.returns` |
| 반납 유형 · 창고 · 결재 판정 | 업무 규칙 함수 (데이터가 아니다) |
| 연관 자재 | 업무 `DB_BIZ.sets` + 정본 조인 |

반납을 실행하면 `DB.txn({type:'반납', qty})` 로 3층에 쌓인다.
**현재고를 고쳐 쓰지 않는다.** 재고는 `스냅샷 + Σ 트랜잭션` 으로 매번 계산한다.
