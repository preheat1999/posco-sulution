## 영역별 규격

### 사이드바 `.side` (`nav.js` 하나가 그린다)

| 요소 | 내용 |
| --- | --- |
| 로고 | 30x30 파란 라운드 사각형에 「자」 + 「AI 자재 / 솔루션」 |
| 그룹 라벨 | `관리` `분석` `업무` · 10.5px / 700 / letter-spacing .06em / muted |
| 항목 | 아이콘 + 이름 · 13px · padding 9px 10px · radius 10 |
| 선택된 항목 | `--brand-weak` 배경 + `--brand` 글자 + 700 |
| 숫자 배지 | 항목 오른쪽. 해야 할 건수 (적정재고 ④ 처럼) |
| 부제 | 항목 아래 작은 글씨 (「(0건이 네 개)」 「(메일 발송)」) |
| 하단 | 위에 1px 선 + 내 이름 · 소속 · 로그아웃 |

메뉴 구성

```
관리   Dashboard              -> main
       데이터 근거             -> evidence
분석   속성값 판단             -> attr
       적정재고 분석           -> stock
       정비계획 소요 발주       -> plan
       주간 리포트             -> report
업무   구매신청 (PR)           -> purchase
       자재반납 (QR)           -> return
```

각 페이지는 `<head>` 에 `window.PAGE = 'attr'` 처럼 자기 키만 두고
`<aside class="side" id="side">` 를 **비워 둔다.**

### 상단 바 `.top`

* 왼쪽 · 햄버거(960px 이하만) + 빵조각 + `h1`
* 오른쪽 · 요약 알약(`.pill`) · 도구 버튼(`.btn line sm`) · 아바타(36px 원)
* 빵조각은 `부문 · 파트 · 섹션 · 화면그룹` 형태. 로그인에서 고른 소속이 들어간다

### 설명 배너 `.infobar`

첫 줄만 보이고 오른쪽 위 「자세히」 를 누르면 펼쳐진다.
**왜 이 화면이 필요한지**를 적는다. 기능 설명이 아니라 문제 설명이다.

### 챗봇 위젯 (`chat.js`)

오른쪽 아래 고정 원형 버튼. 누르면 대화창이 열린다.
셸을 쓰는 모든 화면에 붙는다. 서버가 없으면 **시연 모드**로 떨어져
준비된 예시 답변을 보여 준다. 자세한 것은 `프롬프트/C_챗봇_연동계약.md`.

### 둘러보기 (`tour.js`)

왼쪽 아래 고정 버튼. 첫 방문이면 자동으로 뜬다.
`?notour=1` 을 주소에 붙이면 뜨지 않는다 (**캡처와 검사에 반드시 필요**).

## 절대 규칙

* 클래스 이름은 고정이다. `.layout` `.side` `.main` `.top` `.top-left`
  `.top-right` `.overlay` `.card` `.btn` `.badge` `.pill`
* **없는 클래스를 만들지 않는다** · `.shell` `.ptitle` `.psub` `.btn-primary`
* 제목은 `.top` 안의 순수 `<h1>` 이다
* `.overlay` 가 없으면 햄버거가 동작하지 않는다
* 스크립트 순서를 지킨다 (`프롬프트/공통_규칙.md` 참고)
