# 01 · 반입 판단 기준

주최측 안내를 그대로 적어 두고, 이 폴더의 파일 하나하나를 어느 항목으로
판단했는지 남긴다. **질문받으면 이 문서를 보여 준다.**

---

## 주최측 안내 (원문)

> 본선 전까지 아래 항목은 자유롭게 준비하셔도 됩니다.
>
> * 과제 수행에 필요한 데이터
> * 서비스 및 화면 구성에 활용할 이미지 · 디자인 자료
> * AI 활용을 위한 프롬프트
> * 기타 기획 및 아이디어 구체화를 위한 참고자료

>

>

> 중요하게 보고 있는 만큼, 코드 작성 및 실제 개발은 반드시 본선 시작 이후
> 진행해 주세요.

## 판단 원칙

```
가져간다   실행되지 않는 것 · 데이터 · 그림 · 문서 · 프롬프트
안 가져간다  실행되는 것 · .html .css .js .py 소스 파일 일체
```

**「실행 가능한 파일이 하나도 없다」** 를 기준으로 삼았다.
이 폴더에는 `.md` `.csv` `.json` `.png` 만 있다.
브라우저나 파이썬으로 **열어서 돌릴 수 있는 파일은 하나도 없다.**

## 애매한 것에 대한 판단

### 디자인 스펙에 적힌 색값 (`#5570F1` 등)

**디자인 자료로 판단했다.**
주최측이 「이미지 · 디자인 자료」 를 명시적으로 허용했고, 색값 · 여백 ·
글자 크기는 디자인 자료의 본체다. 표와 문장으로 적혀 있고 `.css` 파일이 아니다.

### 와이어프레임 안의 클래스 이름 (`.card` `.btn`)

**규격 문서로 판단했다.** 이름만 적혀 있고 스타일 정의가 아니다.
「이 이름을 쓰기로 한다」 는 **약속**이지 구현이 아니다.

### DB 계약서 안의 API 시그니처 (`DB.item(q, dept?)`)

**인터페이스 명세로 판단했다.** 함수 몸통이 없고 이름과 인자만 있다.
이건 「무엇을 만들 것인가」 이지 「만든 것」 이 아니다.

> 이 판단이 걱정되면 **DB_계약서 6절만 빼고 가져가도 된다.**
> `프롬프트/A_백엔드_02` 에 같은 내용이 지시문(프롬프트) 형태로 들어 있어서
> 계약서가 없어도 만들 수 있다.

### 프롬프트 안의 코드 조각

**실행되는 블록은 뺐다.** 로직은 전부 말로 적었다.

```
X  나쁜 예   const SIGN = { '반납': +1, '불출': -1 };
O  좋은 예   부호는 반납 +1 · 입고 +1 · 불출 -1 · 공용전환 -1
```

**남겨 둔 것 두 가지**와 그 이유.

| 무엇 | 어디 | 판단 |
| --- | --- | --- |
| `속성:값` 한 줄 메모 (`.top-right{flex:none}` 등 10곳 남짓) | 디자인 스펙 · 프론트 프롬프트 | **디자인 자료.** 「무엇이 잘못됐었는지」 를 가리키는 메모다. 파일이 아니라 문장 안에 있고, 빼도 「좁은 화면에서는 상단 바를 두 줄로 내린다」 는 문장만으로 만들 수 있다 |
| JSON 요청 · 응답 모양 | 챗봇 연동 계약 | **인터페이스 명세.** 주고받을 데이터의 모양이지 처리 코드가 아니다 |

파이썬 · 자바스크립트 **블록은 하나도 없다.** 붙여 넣어 돌릴 수 있는 것이 없다.

### 데이터 안의 `reason` 문자열

`비핵심보험[C] μ_LT+SS(Z1.28)=2,상한4→2` 같은 값이 들어 있다.
**데이터다.** 화면에 그대로 표시하는 값이고 실행되지 않는다.

## 안심 재료 · 이 판단이 맞는 이유

**코드 없이 데이터와 문서만으로 다시 만들 수 있는지 실제로 해 봤다.**
`검증기록.md` 에 결과가 있다.

```
CSV 만 보고 데이터층을 다시 만들어 원본과 대조   필드 불일치 0건
그 재현본으로 화면 13개 렌더                    오류 0건
```

즉 **이 폴더는 「코드의 대체물」 이 아니라 「코드를 만들 재료」** 다.
재료를 가지고 현장에서 만드는 것이 대회의 취지에 맞다.

## 혹시 지적받으면

```
1  이 문서를 보여 준다
2  "실행 가능한 파일이 하나도 없습니다. .md .csv .json .png 뿐입니다" 라고 말한다
3  그래도 문제가 되는 파일이 있으면 그 자리에서 지운다
     -> 지워도 만들 수 있게 서로 겹치도록 써 두었다
        (계약서를 지워도 프롬프트로, 프롬프트를 지워도 와이어프레임으로)
```

**가장 안전한 최소 조합**은 이것이다. 이것만 있어도 하루면 만든다.

```
데이터/          (데이터)
이미지/          (이미지)
디자인/          (디자인 자료)
프롬프트/        (프롬프트)
```
