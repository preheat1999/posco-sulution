## 1. CSV 만으로 데이터층을 다시 만들 수 있는가

기존 코드를 전혀 보지 않고, `데이터/` 의 CSV 와 `DB_계약서.md` 만 보고
생성기를 새로 써서 자산을 다시 만든 뒤 **원본과 필드 단위로 대조**했다.

```
[자재 정본]  원본 743행 · 재현 743행    모든 필드 일치
[부서]       원본   1행 · 재현   1행    모든 필드 일치
[설비]       원본  14행 · 재현  14행    모든 필드 일치
[정비계획]   원본 156행 · 재현 156행    모든 필드 일치
[판정]       원본 743행 · 재현 743행    모든 필드 일치
[재고]       원본 743행 · 재현 743행    모든 필드 일치
[정체]       원본 262행 · 재현 262행    모든 필드 일치
[요약]                                  모든 값 일치
[명세 상수]                             일치

=> 필드 불일치 0건 · 생성 소요 0.03초
```

### 처음에는 102행이 어긋났다

`holdStd`(설치 수 기준)가 원본은 숫자 `1` 인데 CSV 를 다시 읽으면 문자열 `'1'`
이었다. **CSV 는 타입을 잃는다.** 이 값은 보험품 목표 산식의
`max(raw, 설치수기준, 1)` 에 쓰이므로 문자열로 두면 산식이 조용히 틀린다.

그래서 `데이터/스키마.json` 을 추가했다. 컬럼마다 타입이 적혀 있고
그대로 되돌리면 0건이 된다.

> **「돌아간다」 와 「같은 값이 나온다」 는 다르다.**
> 대조해 보지 않았으면 몰랐을 일이다.

## 3. 불변식 검사가 정말 작동하는가

검사기를 만들어 놓고 통과만 보면, **검사가 아무것도 안 보고 있어도 모른다.**
그래서 일부러 깨뜨려 봤다.

| 깨뜨린 것 | 결과 |
| --- | --- |
| 화면에 정본에 없는 코드 `Q9999999` 삽입 | 불변식 1 이 잡음 |
| `db-biz.js` 에 `name: '가짜품명'` 삽입 | 불변식 3 이 잡음 |
| 요약의 `zeroTarget` 을 413 -> 999 로 | 불변식 5 가 잡음 |

셋 다 잡혔다. 되돌리니 다시 0 problems.

### 그 과정에서 진짜 버그가 나왔다

불변식 1 이 **아무것도 매치하지 않고 있었다.**
셸 heredoc 으로 정규식을 넘기다가 `\b` 두 개가 **실제 백스페이스 문자(0x08)**
로 파일에 들어갔다. 파이썬은 오류를 내지 않고 그냥 백스페이스를 찾는
정규식이 됐다. grep 출력도 정상처럼 보였다 (터미널이 0x08 을 앞 글자
지우기로 처리한다).

고치고 나니 즉시 네 건이 걸렸다.

```
return.html          자재식별표 QR 버튼이 정본에 없는 Q4046778 로 링크
                     -> 누르면 「자재코드가 없습니다」 화면
mobile-return.html   예시 주소와 입력 placeholder 가 죽은 코드
material-view.html   안내 문구의 형식 예시가 실제 코드처럼 읽힘
assets/db-biz.js     옛 버그를 적어 둔 주석에 죽은 코드
```

**그래서 검사기에 「소스에 제어문자가 박혀 있는지」 검사를 넣었다.**

## 4. 좁은 화면에서 정말 보이는가

430px 로 13화면을 전부 찍어 봤다. **다섯 군데가 깨져 있었다.**

| 무엇 | 증상 | 원인 |
| --- | --- | --- |
| 상단 바 | 제목이 「속 / 성 / 값 / 판 / 단」 세로로 쌓임 | `.top-right{flex:none}` 이 안 줄고 `.top-left{min-width:0}` 이 0 까지 눌림 |
| 칩 · 탭 | 「전체」 가 「전 / 체」, 「자세히」 가 「자 / 세 / 히」 | flex 자식의 min-content 가 한글은 **한 글자** |
| 표 카드 모드 | 「변경」 이 「변 / 경」 | `td{display:flex}` 라 td 안의 칩도 flex 자식이 됨 |
| 진행 파이프라인 | 「QR 스 / 캔」 | 격자 자동 배치에 맡겨 단계명이 좁은 칸으로 밀림 |
| 아코디언 머리 | 「PR 대 / 상 자재」 | 긴 배지가 flex:none 이라 제목 칸이 사라짐 |

**원인이 사실상 하나다.** flex 자식은 `min-width:auto` 라 min-content 폭까지
줄어드는데, **한글은 글자마다 줄바꿈이 되므로 min-content 가 한 글자**다.
`flex:none` 인 형제가 옆에 있으면 줄어드는 쪽만 계속 눌린다.

처방도 하나다. **좁으면 줄을 넘긴다** (`flex-wrap:wrap`), **칩은 안 줄인다**
(`white-space:nowrap` · `flex:none`).

전부 고쳤다. **데스크톱에서는 전혀 드러나지 않는 것들이다.**
세로로 긴 캡처를 찍어 보고서야 보였다.

### 아직 남은 것 (당일에 반드시 반영)

```
좁은 화면에서 긴 목록을 전부 그리면 문서 높이가
  속성값 판단   189,000px
  적정재고      204,000px
가 된다 (실측). 743행이 카드 743장으로 펼쳐지기 때문이다.

-> 처음 20장만 그리고 「더 보기 (남은 N건)」 버튼을 둔다
   디자인 스펙 5.2 에 적어 뒀다
```

### 캡처할 때의 함정

헤드리스 크롬은 창 너비를 **약 500px 아래로 못 내린다.**
`--window-size=430,900` 을 주면 500px 로 렌더한 뒤 430px 만 잘라 준다.
**오른쪽이 잘린 것처럼 보이는 가짜 스크린샷**이 나온다.
430px iframe 을 넉넉한 창에 넣고 찍어야 한다.
